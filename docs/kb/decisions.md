# Решения по частям ReactOS: берём, обновляем, заменяем, пишем сами

Правило владельца: из ReactOS берём только то, что годно в 2026 году и лучше всех доступных вариантов.
Подробности и доказательства (файл:строка, источники) — в `reactos-core.md`, `reactos-drivers.md`,
`reactos-usermode.md`, `reactos-build.md`. Здесь — итог, который применяем.

## Сборка

| Что | Решение | Почему |
|---|---|---|
| Компилятор | **clang 18+ и mingw-w64 из дистрибутива** вместо RosBE GCC 8.4 | RosBE — GCC 2020 года, собирается скриптом из чужого gist; clang свежий, Ubuntu 24.04 даёт его пакетами. Три правки уже внесены (SSE-встроенные функции, `dlltool`, модель исключений), плюс `_alloca` и float-математика x86 |
| Уровень функций (`DLL_EXPORT_VERSION`) | **0x600 сейчас** → 0x601 → 0x602/0x603 → 0xA00 | Цель — Windows 10. Шаги и что сделать до каждого — `reactos-usermode.md`, раздел 5 |
| Версия ОС для программ | сейчас 5.2, **10.0 — только после шага 0xA00** | иначе программы пойдут по путям Windows 10, которых у нас ещё нет |
| Уровень заголовков ядра (`_WIN32_WINNT` 0x502 у ядра, HAL, загрузчика) | поднимать **один раз, сразу у всех трёх**, на этапе 2 | у них общие структуры; поднятие по частям ломает загрузку |

## Загрузка, ядро, HAL

| Часть | Решение |
|---|---|
| Ядро NT (ntoskrnl) | **оставляем и дописываем**: замены с совместимой лицензией нет. Не хватает ~150–200 системных вызовов Windows 10, ALPC, `NtCreateUserProcess`, `NtCreateThreadEx`, `NtWaitForAlertByThreadId`, памяти `*Ex`, признаков повышения прав в токенах |
| Многоядерность x64 | **писать**: запуск ядер на amd64 — заглушки (`KeStartAllProcessors`) |
| WoW64 | **перенести из Wine 11.x** (wow64/wow64cpu, LGPL); часть с графическими вызовами переделать под наш win32k |
| HAL | **только ACPI+APIC**, остальные варианты (PIC, MPS, PC-98, Xbox, ARM) не собирать. Дописать MSI/MSI-X, PCIe ECAM, HPET, подключить x2APIC, перезагрузку через ACPI |
| Скрытая ошибка `IoConnectInterruptEx` | **исправить первым делом на этапе 3**: для MSI возвращает «успех», ничего не подключив — драйверы Windows 10 зависают |
| Загрузчик | **UEFI-загрузчик ReactOS оставляем и доводим** (передать ядру службы UEFI, SMBIOS из таблиц UEFI, раздел EFI и пункт загрузки при установке). BIOS-загрузка — только для CI |
| RTL | оставляем; дописать `RtlWaitOnAddress`; пул потоков и контексты активации обновить до Wine 11.x; LFH-куча из Wine |
| Реестр | оставляем; дописать `NtRenameKey`, `NtRestoreKey`, `NtReplaceKey`, `NtQueryMultipleValueKey`, двойные журналы |
| Питание, ETW, аварийные дампы | **писать по WDK**: ETW-минимум — этап 1, дампы — этап 2, сон/гибернация/PoFx — этап 4 |
| Системные процессы | оставляем, доводим SCM (отложенный запуск, SID служб, триггеры, `NotifyServiceStatusChange`); консоль — **conhost из microsoft/terminal (MIT)** + свой `condrv.sys` (ConPTY); NTVDM из x64 убрать |
| ACPICA | обновить до 20260930 и **брать под BSD-3** (в списке ReactOS она записана как GPL-2.0 — это сделало бы сборку GPLv2-only) |
| `acpi.sys` | **переписать на uACPI (MIT)**: все 9 функций `ACPI_INTERFACE_STANDARD` — заглушки, нет EC; заготовка `acpi_new` уже в дереве |

## Драйверы

| Часть | Решение |
|---|---|
| ATA/AHCI (новый atapi + pciidex) | оставляем; чинить падение x64 на i440FX |
| PCI | переходим на **pcix** (ECAM, PCIe, Resizable BAR уже есть); старый `pci.sys` с заголовком из Linux — убрать |
| StorPort | **дописать до уровня Windows 10** (реализовано 4 из ~35 расширенных функций) |
| NVMe | **добавить**: порт OFA nvmewin 1.5 (BSD) как минипорт StorPort |
| USB 2, классы ввода, HID | оставляем |
| USB 3 (xHCI/UCX/hub3) | **переписать внутренности** по образцу Haiku (MIT) и FreeBSD (BSD) |
| NDIS | **6.50+ с прослойкой для NDIS 5**; встроенные драйверы Intel I219/I225, Realtek 8111/8125 |
| TCP/IP | протокол NDIS 6 на **lwIP 2.2.1** с IPv6 |
| Wi-Fi | хост WDI + wpa_supplicant (BSD) — этап 4 |
| WDF | **обновить до KMDF 1.33 / UMDF 2.33** (сейчас 1.17 — драйверы новее не грузятся); добавить среду UMDF 2 |
| HD Audio | шина (CoolStar) оставляем, **добавить драйвер кодека** |
| Видео | **добавить драйвер кадрового буфера UEFI GOP** (этап 3); **dxgkrnl** с нуля, первым тестом — образец Microsoft KMDOD (этап 5) |
| I2C/GPIO (тачпады) | **добавить** SpbCx/GpioClx, hub ресурсов ACPI, hidi2c (этап 4) |
| CNG (`cng.sys`) | **добавить на SymCrypt (MIT)** |
| NTFS | **своя реализация чтения и записи** на основе драйвера ReactOS (запись сейчас экспериментальна); ядро ntfs-3g не берём — это перенос пользовательской библиотеки в ядро с её моделью памяти, дороже, чем довести своё |
| WinBtrfs | обновить 1.8.1 → 1.10, держать отдельным .sys (LGPL-3.0) |
| Сторонние драйверы MS-PL (classpnp, disk, cdrom, fastfat, cdfs) | оставляем **только отдельными .sys** |
| Убрать устаревшее | ISA PnP, pcmcia, дисковод, buslogic, uniata, atapi_old, inport, sermouse, LPT, nvnet, ne2000, старые звуковые карты, pc98vid, xboxvmp, vga_new, vmx_svga, vfatfs, fbtusb |
| Лицензии под вопросом | storahci, processr, fdc — GPLv2 без «or later»; `atapi_old` (EULA Microsoft) и `vga_new` (NT4 DDK) — несовместимы; `pci/pcidef.h` — из Linux. Всё это уходит при замене/удалении выше |

## Пользовательский режим

| Часть | Решение |
|---|---|
| ntdll, kernel32, user32, gdi32, win32k | **оставляем свои** (завязаны на CSRSS, ядро и вызовы win32k); PE-половину ntdll и user32 дополняем из Wine по частям |
| kernelbase | **взять настоящий из Wine 11.x**, kernel32 перенаправляет в него (сейчас `kernelbase_ros` — 200 функций) |
| API-sets | **разрешать всегда**, как Windows 10 (сейчас — только по GUID из манифеста программы: из-за этого молча закрываются Python 3.13 и Firefox); сравнивать имя до последнего дефиса; цели вызовов исправить (kernelbase, combase, shcore) |
| Падающие заглушки `@ stub` | **реализовать те, что вызывают программы** (110 в kernel32 при 0x600, 95 в ucrtbase) |
| ucrtbase | собрать C99-математику из уже лежащего `dll/win32/msvcrt/math.c` (Wine) |
| DLL из Wine, которых нет у нас | **переносить инструментом `tools/wine/import_dll.py`** из Wine 11.20: 307 переносимых DLL (`netprofm` — первая) |
| Синхронизированные с Wine DLL | обновить с 10.x до 11.x |
| TLS | schannel на **mbedTLS 3.6 LTS** (TLS 1.3; лицензия Apache-2.0 OR GPL-2.0-or-later — берём GPL-ветку) вместо 2.16 |
| OpenGL/Vulkan/Direct3D | Mesa 2.6 (OpenGL 1.1) → **Mesa llvmpipe/lavapipe**; загрузчик Vulkan; D3D9–12 — **DXVK/VKD3D-Proton** поверх Vulkan |
| Звук для программ | WASAPI поверх KS (`audioses`, служба конечных точек) |
| Media Foundation, XAudio2, WinRT, ICU | переносить из Wine (см. `services.md`) |
| Сторонние библиотеки | FreeType 2.10 → 2.15, zlib 1.2.13 → 1.3.x, libxml2 2.10 → актуальная. STLport (заброшен) — заменить; libc++ и MS STL под Apache-2.0 с исключением LLVM, совместимость с GPLv2 проверить до переноса, иначе — libstdc++ (GPL с исключением GCC) |
